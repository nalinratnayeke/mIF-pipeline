# Experimental InstanSeg reconciliation data

This directory is reserved for temporary, reproducible artifacts generated by
`notebooks/experimental_instanseg_watershed_reconciliation.ipynb`.

The notebook records the source OME-TIFF, GeoJSON feature, full tumor bounding
box, and exact full-resolution test-crop coordinates in `manifest.json`. The
saved OME crop contains only the channels explicitly selected near the top of
the notebook, in the same order used for inference. Saved masks and QC files
include a short hash of the explicit InstanSeg settings, with a companion
settings JSON, so parameter-tuning runs do not silently overwrite one another. Large
OME-TIFF, mask TIFF, CSV, and NPZ outputs are intentionally git-ignored. They
are postprocessing experiment artifacts and are not inputs to the production
mIF pipeline.
